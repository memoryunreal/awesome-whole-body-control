# WholeBodyVLA 精读：上层动作语义与下层移动接口必须一起设计

**论文**：[WholeBodyVLA: Towards Unified Latent VLA for Whole-Body Loco-Manipulation Control](https://arxiv.org/html/2512.11047v2)。**团队**：Fudan、HKU OpenDriveLab / MMLab、AgiBot、SII。**核读版本**：arXiv v2；2026-10-19 核查正文、附录与[官方项目](https://opendrivelab.com/WholeBodyVLA/)。AI 辅助精读，未运行复现实验。

## 1. 最值得记住的问题

上层模型已经决定“停在箱子旁边”，底层却继续向前、转弯时漂移，整任务仍会失败。WholeBodyVLA 同时研究两件事：如何用低成本视频预训练移动与操作语义，以及如何让下层准确执行这些决策。它比只研究人手动作预训练更直接贴近人形全身移动操作。

## 2. 为什么移动和操作各学一个潜在动作模型

操作视频里的画面变化主要来自手臂，移动视频则包含大量相机运动。直接把二者交给同一个潜在动作模型，可能把不同原因造成的视觉变化混在一起。论文分别训练 manipulation 与 locomotion LAM，再让 VLA 联合预测两类潜在动作；机器人专属解码器把它们落到上肢关节和移动命令。[§3.1](https://arxiv.org/html/2512.11047v2#S3.SS1)

“统一”指联合决策与协同学习，不代表取消了模块分工。潜在动作也不是物理可执行性的证明：最终仍需机器人数据适配，以及能可靠完成命令的下层控制器。

## 3. LMO 改变的不是单纯速度上限

下层使用前后、侧向和转向的离散方向指示，加上目标高度。通过显式启动与停止、参考平滑、两阶段课程，以及来自操作动作的结构化扰动训练，让控制更贴近走到目标位置再操作的需求。[§3.2](https://arxiv.org/html/2512.11047v2#S3.SS2)

**我们的判断**：高层接口越丰富并不一定越好。若任务只需要可预测的小范围移动，把所有速度组合都交给上层反而增加学习与控制不确定性。但离散接口也有表达力边界，遇到连续速度调节、复杂地形或动态避障，需要另行验证。

## 4. Table 2 的 78% 不是三任务完整成功率

| 方法 | 六个子目标的平均分 |
|---|---|
| 模块化基线 | 64.0% |
| GR00T + LMO | 42.0% |
| OpenVLA-OFT + LMO | 56.7% |
| WholeBodyVLA | 78.0% |
| 换成速度型下层 | 54.0% |
| 去掉 LAM | 39.3% |

来源：[Table 2](https://arxiv.org/html/2512.11047v2#S4.T2)。三个任务各拆成两个子目标，每项分母为 25；78% 是六列成绩的平均。完整模型三个第二子目标分别为 13/25、17/25、22/25，因此不能把 78% 直接写成整任务成功率。与 54% 的差为 **24 个百分点**，也不应写成相对提高 24%。

## 5. 这个对照怎样支持方法

各 VLA 基线在相同 X2 遥操作数据上微调，并接入 LMO；因此对比不仅是给不同模型配不同底盘。另有 LMO 课程与方向准确性消融，分别检查移动误差和操作时质心摆动。[§4.1、§4.4](https://arxiv.org/html/2512.11047v2#S4.SS1)

不过预训练数据和模型来历不同，仍不能把最终差距全部归因于一个组件。去掉 LAM 同时改变了预训练先验，换掉 LMO 则改变执行系统；需要分别解释其影响，不能合并成“模型架构带来全部提升”。

## 6. 平台与负载结果的正确边界

真机为 AgiBot X2 原型机，具有双臂、双腿、腰部、Omnipicker 夹爪和 D435i。任务包含装袋、装箱和推 50 kg 小车，论文描述每任务 50 次采集执行。[§4.1](https://arxiv.org/html/2512.11047v2#S4.SS1)

推小车的 50 kg 是车的负载尺度，不等于双臂悬空搬起 50 kg。X2 与 G1 的关节、手部和执行接口也不同；迁到我们的平台，首先要重新检查命令语义和带载稳定性，而不是直接替换模型配置中的机器人名称。

## 7. 我们下一步应借鉴什么

先固定同一上层策略，比较速度命令与带显式启停语义的命令；然后固定下层，再比较视频预训练是否减少机器人示教需求。分别记录停止距离、转向漂移、到位后的手部误差与子目标转换成功率。

这样可以判断失败发生在决策、执行还是接触阶段，也能防止把下层漂移误归因于视觉模型。长时规划、复杂灵巧操作、遮挡与动态场景仍是论文保留的限制；不能由三个任务外推为通用全身自主系统。[§5](https://arxiv.org/html/2512.11047v2#S5)
